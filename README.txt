NEXUS as an installable app (PWA)
1. Upload this whole folder to any HTTPS static host (Netlify Drop, GitHub Pages, Cloudflare Pages, Vercel).
2. Open the hosted address on your phone.
   iPhone: Safari > Share > Add to Home Screen.   Android: Chrome menu > Install app.
3. It then opens full screen with its own icon and works offline.
Notes: data stays on that device (local storage). The Claude cloud backup only works inside Claude; use Settings > Your data (export/import JSON) elsewhere.
